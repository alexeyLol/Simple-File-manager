## Getting Started

* Install Cargo (Rust)  
* Execute `cargo install kaa_file_manager`  
* Run - `kfm`

Now You can manage files and directories: find, read, write and more!


## Convenience

- [x] Work in one directory - You can open any folder and manage your data there.

- [x] In Your terminal - in order not to be distracted by opening extraneous applications.

- [x] Colored interface with selection, **not just typing**.

- [x] Rust provides good performance and safety.
